# Neutral wire v1

This crate deliberately has no dependency on the Nushell SDK. It transports descriptors and does not promise universal Nushell roundtrips, execute closures, expand globs, enumerate ranges, or reopen paths.

Grammar: magic `R3V1`, then frames prefixed by a u32 big-endian MessagePack byte length. Each frame is one exact MessagePack object. Serialization uses maps, internally adjacent tagged enums with `type`/`value` and snake_case variant names. Start is `{type: start, value: {version: 1, cwd: ..., origin: ...}}`. Payload values also use explicit tagged enums. Binary and Bytes serialize as MessagePack binary via serde_bytes. Float stores f64, including special values and bit patterns. Date stores a validated RFC3339 string preserving its offset.

Start must be first and unique. `single_value` requires one Value; `list_stream` accepts zero or more Values; `byte_stream` accepts only Bytes; `absent` accepts no payload. Ping is legal after Start and before End. End is mandatory and EOF must follow it. Bytes chunks are at most 64KiB. String streams validate UTF-8 after concatenation, allowing multibyte characters to cross chunk boundaries. Binary and Unknown keep their identities, including empty streams. Unknown is never inferred as String.

Budgets: maximum 16MiB per frame, 128MiB per complete transport including magic, prefixes and Ping, 64 Value levels (root counts as one), one million semantic Value nodes accumulated across frames, 256 MessagePack levels, eight million MessagePack nodes accumulated across frames. Record keys must be unique. Iterative preflight bounds every MessagePack length, validates that the complete object exists, and checks wire depth before recursive serde decoding with an explicit depth limit. The scanner allocates only its bounded depth stack. Value validation is iterative and cancellable.

`Reader::read_start` consumes only magic and Start. The application can immediately reject an argument combined with present pipeline input while the producer remains open. `finish` validates the entire finite stream and rejects incomplete/trailing data. No partial successful result is returned. The caller passes an Arc<AtomicBool>; checks occur between read chunks and during validation. A blocking Read requires OS handle/worker cancellation by the owner, and waiting for EOF after End can also block.

`write_magic`, `write_frame`, and `write_frame_cancelable` support producers. A capped temporary writer prevents any frame encoding buffer from exceeding 16MiB. Producers must enforce complete-stream budgets and grammar, and abandon a failed writer rather than continue after a partially written I/O frame. Cancellation cannot interrupt a blocking Write either.

`TypedInput::typed_text` is an initial explicit textual representation, not executable Nushell. Root String values and String streams remain literal. Other payloads retain type labels and record ordering; float values include their bit pattern. The application owns terminal escaping and presentation. Navigation, search and graphical QA are outside this crate.
For worker monitoring, Reader::with_progress accepts an Arc<AtomicU64> content counter. Successfully processed Start, Value, Bytes and End increment it; Ping never does. The owner can enforce an inactivity deadline without treating Ping as content progress.
messagepack_node_count validates and counts one bounded MessagePack frame payload without deserializing it. Producers accumulate its returned counts against the public MAX_WIRE_NODES budget, including Start, Ping and End; payload excludes magic and length prefix.
