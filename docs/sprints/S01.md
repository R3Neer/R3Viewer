## Contrato de aceptación

- Argumento abre archivo local; -v/--value interpreta literal. -p/--path y -v incompatibles. stdin externo sin argumento es texto UTF-8, incluso vacío; -v/--value sin argumento permite ese mismo stdin literal, no cambia su contenido; nunca inferir ruta/URL del contenido. Sin argumento y stdin TTY: error CLI 2.
- Un origen: múltiples argumentos o argumento más stdin con contenido error 2; stdin EOF vacío acompañado de argumento se admite. stdin textual con --path se rechaza explícitamente hasta framing Nu tipado S02. URL posicional detectada: capacidad remota todavía pendiente, error 1; --path conserva interpretación local.
- --format text disponible; otros formatos diagnosticados como capacidad no incluida. No afirmar soporte Markdown/HTML enriquecido ni binario.
- -i/--inline imprime y termina; stdout redirigido activa texto sin TUI. Contenido stdout, diagnósticos stderr, sin banners. Preservar UTF-8, espacios, tabulaciones y saltos; representar controles de terminal peligrosos de forma visible, no ejecutarlos.
- Límite experimental S01: 128MiB para archivo/stdin, error explícito al exceder sin presentar prefijo como documento completo. Entrada UTF-8 inválida error 1. Lectura bloqueada cancelable, código 130.
- Sesión cuando stdout y terminal de control sean utilizables: scroll vertical/horizontal, inicio/fin, páginas, ayuda, resize, q/Escape salida 0 y Ctrl-C 130. RAII y manejo de errores restauran entrada/cursor/pantalla. stdin de datos no sirve como teclado. Sin controlTTY: texto, sin raw-mode.
- Códigos: 0 normal, 1 IO/render/limitación fatal, 2 CLI/config, 130 cancelación. Propagación Nu se comprueba usando binario real.

## Diseño acotado

Un crate inicial Rust con módulos cli/input/text/session. Documento de texto con fuente/procedencia y líneas, sin secuencias ANSI en el modelo. CLI valida antes de IO. Lectura cancelable con trabajador y canal; main propietario de sesión/control. Crossterm y controlTTY para interacción, sin consultas gráficas en S01. Preparar fronteras para adaptadores futuros sin motor gráfico ni tipos Nu simulados.

## Riesgos y pendientes

Biblioteca de terminal debe usar handles de control al tener stdin ocupado. Pruebas automáticas no certifican Windows Terminal/WezTerm ni macOS/Linux. No copiar corpus privado al repo. Sin instalación del producto ni publicación.
