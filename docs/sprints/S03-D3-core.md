## 1. Integración y propiedad

Un `yaml_worker::project` devuelve el mismo `(Structure, syntax_depth, key_components)` que TOML/JSON; dispatch en structure_worker, mismo StructureClient, lease, ChildJob, deadlines, cancellation y reap. Sin DOM, worker nuevo, hilo adicional, constructor YAML, framework de nodos ni transporte Nu nuevo. Incluir el parser privado R2 como dependencia local vendorizada solo al implementar el detalle aprobado; conservar todos los archivos originales excepto los dos patches aprobados, licencia principal y `.licenses/*` de Chen Yuheng/Ethiraric. Registro de procedencia/hashes y diff frente al crate0.1.0 antes de dependencia/lockfile. Sin hook adicional de tokens.

Structure mantiene `format` de confianza establecido por request/proyector y comprobado por receptor, no inferido de kinds. Ampliar StructureFormat conYaml; APIs de builder existentes siguen por defecto/formato explícito TOML/JSON sin relajar sus invariantes. Los únicos tipos nuevos son YamlStream, YamlDocument, Alias y YamlTaggedScalar. Los dos primeros son containers; Alias es referencia terminal sin entries y sin text scalar; YamlTaggedScalar conserva decoded text pero no afirma categoría Core. Mapping/Sequence y categorías scalar existentes se reutilizan. `EntrySpec{key:Option<NodeId>,value}` permanece.

YAML siempre construye Stream→Document→root, incluso con un documento; presentación TUI puede comenzar en root único manteniendo identidad/ordinal de Document, y Back permite inspeccionarlo. Stream vacío tiene un nodo Stream y cero Document, nunca null sintético. Document explícito vacío tiene Document+Null implícito; el Null tiene decoded vacío y locationNone. Stream/Document tienen locationNone: un delimitador no es un token value ni un extent de documento. Raw scalar es exclusivamente location validada en fuente; decoded es `NodeSpec.text`, Source cuando idéntico al token íntegro, Cooked en cualquier otra situación, incluido quoted numeric. Quoted vacío tiene span de quotes y text vacío; null lexical tiene span; ausencia de token scalar no tiene span.

Dos arenas laterales solo YAML: `parents: Vec<Option<ParentLink>>`, ParentLink{owner:NodeId,ordinal:u32,part:Key|Value}, y metadata sparse ordenada por NodeId. Un registro metadata lleva doc ordinal, style opcional, anchorID opcional, tagURI TextRef opcional, AliasTarget{anchorID,target:NodeId} opcional y flags Document(explicitStart, syntheticRoot). IDs parser convertidos checked a u32. Metadata no usa strings independientes: tagURI se concatena handle+suffix hacia cooked, sin Display de Tag, separador añadido o percentdecode. Alias raw/name se presta del span validado `*name`; si ese token no se acredita se muestra ID/target y locationNone. Anchor muestra ID; nombre y raw propiedad siguen en Fuente si el evento no los expone. No inventar anchor/tag spans ni buscar retrospectivamente propiedades en texto.

Metadata se consulta por búsqueda binaria, sin hashmap por nodo; ParentLink da dirección canónica. Estas arenas existen vacías para TOML/JSON. Los wrappers tienen entries sin key; Document exactamente una; Stream cero o más Documents; el padre de root esNone. Cada Node salvo Stream posee exactamente un padre de serialización. ParentLink es índice derivado, no otro enlace semántico; sí cuenta su capacidad íntegra en memoria. AliasTarget es enlace semántico adicional y jamás padre de serialización.

## 2. Proyección, validación y límites de forma

Consumir API pull sin clone/load, procesando cada evento antes del siguiente. Stack fijo hasta67frames (64containers+Document+Stream y slot de trabajo); cada frame guarda NodeId, kind, pendingKey y buffer de EntrySpec con capacidad contabilizada. Al cerrar mapping debe haber cantidad par y pendingKeyNone; al cerrar container transferir sus entries con set_entries, conservando orden, y soltar su buffer antes de siguiente crecimiento. Los buffers de containers anidados se suman: no cobrar solo el superior. Las entries finales son contiguas por container; no importa su orden global de cierre. Nunca ordenar YAML por posición o label.

Anchor lookup temporal: vector de pares `(parserID,NodeId)` creciente por ID, reserve comprobado y binaria, no vector indexado por máximo ID emitido ni BTreeMap sin presupuesto. Vaciar en DocumentStart sin keep_tags. Registrar anchor en creación de nodo/container antes de descendientes; permite `&a [*a]`. Cada alias debe resolver ID ya registrado del mismo documento. Rebinding obtiene distinto ID; no resolver por nombre ni cambiar destinos previos. Guardar target directo. Parser ya rechaza forward/cross-document, pero adapter y receptor verifican la propiedad nuevamente. El receptor deriva parents, no acepta una tabla enviada por el worker. Comparar profundidad máxima calculada con la reportada; nunca confiar solo en Counts. ## 3. Resolución scalar y tag

Primero tag expandida exacta (percentescapes mantienen hexcase). `!` no específico fuerza String en scalar; no específico en colección conserva shape. URI str fuerzaString. URI null/bool/int/float aplica validación Core al decoded incluso quoted/block; lexical incompatible produce InvalidYamlCoreTag de stream completo. URI seq/map exige shape correspondiente; tag scalar aplicado a colección, o seq/map a scalar/shape contraria, también falla completo. Otros URI, incluidos URI estándar que el perfil no clasifica, son inertes: colección conserva shape+tag; scalar YamlTaggedScalar muestra "tagged scalar (categoría no resuelta)" y decoded sin aplicar Core ni heredar bool/int por plain. Así no se clasifica silenciosamente una etiqueta estándar no implementada. No constructor, filesystem/red o coerción Nu.

Sin tag: estilos quoted/literal/folded→String; Plain aplica Core1.2 en orden null/bool/int/float/String. Match completo, ASCII y sin parse numérico: null vacío/~ /null/Null/NULL; bool true/True/TRUE/false/False/FALSE; decimal entero con signo opcional, octal `0o[0-7]+`, hex `0x[0-9a-fA-F]+`; float gramática decimal/exponente y variantes .inf/.Inf/.INF con signo y .nan/.NaN/.NAN. Implementar recognizers iterativos con checks cancel cada1024bytes, sin regex/BigInt/f64; fixture exacto y tabla de casos contra contrato antes de codificar. Signos octal/hex no aceptados por esa producción Core; valores enormes solo texto. URI null valida vacío también cuando quoted; URI int con decoded12 de escapeUnicode esInteger y rawquoted permanece original. URIcustom lookalike `tag:yaml.org,2002:%69nt` queda TaggedScalar.

Plain decoded vacío nunca demuestra token real: empty_scalar sintético de parser →locationNone aun si span del evento apunta a `...`, `:`, otro indicador o EOF. Literal/folded vacío conserva header; quoted vacío conserva quotes. Únicamente styles con token real tienen raw location. Versiones explícitas distintas de1.2 en cualquier documento: UnsupportedYamlVersion, sin Begin/Ready parcial. Encapsular info del error upstream; no usar ScanErrorDisplay que llama "byte" al índice de caracteres. Fijar códigos de fallo usando información constante del patch/perfil, no un diagnóstico libre usado para decidir semántica.

## 4. Coordenadas y dominios de texto
