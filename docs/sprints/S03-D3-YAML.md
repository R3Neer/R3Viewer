# S03-D3 YAML: contrato observable revisado R2

Contrato observable revisado sin críticas pendientes, según [revisión](../reviews/S03-D3-plan.md). No autoriza integración anterior a JSON aceptado. RV-106 YAML como lector de serialización, conservando fuente, sin prometer composición/validación semántica completa.

## Comportamiento

1. Fuente intacta por defecto. --format yaml/--structure y Tab/BackTab comparten contrato TOML/JSON. Auto/Code solo archivo local real .yaml/.yml; --language solo sintaxis. Literales/stdin/NuString/StringByteStream explícitos; tipos Nu no textuales no se convierten. Redirección fuente por defecto, estructura explícita salida humana no serializer. Sin modificar open ni from yaml existente de Nu.
2. Leer stream completo de eventos YAML1.2, preservando todos documentos incluidos vacíos. Cada documento tiene ordinal estable; no confundir EOF vacío con documento explícito null. Mostrar jerarquía stream→document→nodo cuando hay múltiples; vista de un único documento puede presentar su raíz con identidad de documento retenida. Delimitadores/directivas siguen accesibles en Fuente y metadatos conocidos; no descartar silenciosamente documentos.
3. Mapping conserva pares en orden, sin last/firstwins. Toda clave es un nodo navegable, incluyendo secuencias/mappings/null; no stringificar clave compleja para crear identidad. Pares y documentos direccionados por ordinal independiente de etiqueta. Sequences preservan orden. No expandir merge << como extensión YAML1.1; tratarlo como clave normal.
4. Scalar conserva estilo, token lexical completo y texto decodificado. Resolver categoría por prioridad: URI de tag expandida/no específica primero; sin etiqueta explícita, estilo después y contenido decodificado según Core YAML1.2 para plain (null/bool/int/float/string), quoted/block como string. Tag no específico `!` fuerza string aun en `! true`; resolver `%TAG` antes de decidir categorías, nunca decidir por shorthand `!!str` literal si se ha redefinido el handle. No conversión numérica. Lexemas enteros/flotantes originales son autoridad, incluidos .inf/.nan y números enormes; no cálculo i64/f64 ni coerción a tipos Nu. Diferenciar vacío/null/stringvacío/ausencia. URI estándar resuelta str fuerza string. URI estándar null/bool/int/float clasifica y valida el contenido decodificado aun si quoted: `!!int "12"` es integer con contenido12 y tokenrawquoted intacto; `!!int "\u0031\u0032"` igual sin reemplazar fuente ni fabricar span decoded. Incompatibilidad léxica o URI estándar seq/map aplicada a forma distinta produce Unavailable del stream completo, Source0+diagnóstico específico, ningún Ready parcial. URI estándar de scalar aplicada a colección igual. Otros tags no pertenecientes a esas categorías se mantienen inertes. Un handle!! redefinido a URI custom no hereda coerción estándar. Otras etiquetas custom/URI permanecen metadata inerte, sin constructor, carga ni ejecución. Perfil de versiones: sin directiva o `%YAML 1.2` soportado. Cualquier versión explícita distinta de major1/minor2 (incluye1.1/1.3/2.0), en cualquier documento del stream, produce Unavailable de stream completo, Source0+diagnóstico de versión no soportada; ningún Ready parcial ni schema1.1 silencioso. Esta restricción es perfil explícito de R3Viewer, no se atribuye al parser upstream.
5. Anchors tienen identidad asignada por parser dentro del documento. Alias muestra referencia y nombre/rawtoken si está disponible validado; navegación explícita al target, sin duplicar subtree ni expansión automática. Ciclos válidos no bloquean ni hacen búsqueda infinita. Rebinding respeta target que resolvió parser en ese momento; alias adelantado/no definido es inválido según parser. Búsqueda DFS de árbol de serialización visita nodo Alias como descriptor, no atraviesa su destino. Acción de seguir alias añade un paso al historial y volver recupera posición; ciclo puede recorrerse solo con acciones explícitas. Historial de navegación (incluidos pasos por alias) máximo128entradas; al alcanzar límite rechazar acción con diagnóstico sin perder retorno, truncar historial ni crecer sin límite. Presupuestar metadatos/path/cursor y cancelación en diseño; no guardar duplicados masivos de rutas/subtrees. Ese límite de navegación no cambia validez ni profundidad del documento. Anchors de documentos distintos nunca se mezclan.
6. Pares repetidos se conservan y avisan si las claves scalar-string decodificadas coinciden exactamente. Para otras claves no se afirma validación completa de unicidad semántica/canonicalización; ayuda lo denomina inspector de serialización YAML, no compositor/validador. Si advertencia parcial, etiquetar explícitamente su alcance en diagnóstico. Nunca omitir claves ni convertirlas a hashmap. Una futura validación semántica completa queda fuera de este incremento y no sustituye la navegación requerida.
7. Búsqueda en claves/hojas scalar utiliza contenido decodificado sin normalización para todas categorías. Números plain no se convierten; para números quoted con tag explícito se busca decoded12 aunque tokenrawsea"12" o escapeUnicode. Tokenrawcompleto sigue inspeccionable y es autoridad de Fuente; conservando distinción entre glifo literal y placeholder de control, como JSON R2. Alias/tag descriptor busca metadata mostrada segura; búsquedas de Fuente/Estructura separadas. `o` usa exclusivamente SourceSpan UTF8 validado del token/nodo seleccionado; scalar quoted incluye quotes y block incluye header/indicadores, no comment externo. Propiedades anchor/tag se inspeccionan como metadata y Fuente; un rango sin contigüidad acreditada no se inventa.
8. Misma fuente128MiB, nodos+aristas1M, depth64, persistent+ownscratch64MiB, Profundidad64 cuenta contenedores YAML y subárboles de claves complejas igual que valores, excluyendo wrappers stream/document. Referencias Alias no expanden ni añaden profundidad documental. Wrappers y metadatos sí cuentan en nodos/aristas/memoria; no crear cuota gratuita. childJob512MiB Win, deadlines2sTUI/5sinline/cancel/lease/reap/syntaxmutualexclusion del controlador vigente. No aliasexpansion, no DOMpersistente, metas/spans/cooked/charindexincluidos en presupuesto. Fallo parser/representación/presupuesto/deadline→fuente completa0+diagnóstico y estadoUnavailable latched; manualBuildingcancel reintenta. No Ready parcial. Sin certificación Unix hasta resolver containment/QA ya pendientes.
