# Criterios independientes PDF wire R5 — D0
Fijados antes de leer candidato R5 o outputs de su autor. Base requerida f8017f1. No runtime/D1/D2 requerido para aceptar diseño. Actor R2, Rust R4 y UTF16 R2 son contratos previos, sin adopción implícita de wire histórico.

I01 Protocolo: esquema canónico de bytes endian/offset/tamaño enum y reserved para cada mensaje. Header/body bound antes de reserve; opcode y secuencia cerrados; orden/count/offset checked. Independientes fixtures positivos y mutaciones unknown/duplicate/skip/truncation/overflow/trailing.
I02 Input: snapshot/hash/length/generation/request/page/engine/profile/op identidad exacta; source completo único sin rutas/callbacks; hashing continuo y longitud comprobada; EOF físico requerido. Primera respuesta precoz antes close observado sticky HostError; carreras close/read y errores tardíos tras joins no se borran.
I03 Response: descriptor precede datos, chunks contiguos, body exacto, End/digest dominio exacto y receipts externos completos EOF/exit0/cleanup. Candidate no publica durante Pending/stale/cancel; error transaccional no confunde raster/text. Digests no se derivan del output autor: SHA conocido o fixture independiente.
I04 Metadata y geometría: tamaño, crop/media efectivos, inherencia/defaults/rotation/userunit se contrastan contra primarias 7881. Matrices y dispositivo derivables para crop offset+rotaciones 0/90/180/270, clipping y mosaico; bounding corners y centros/píxeles sin ambigüedad. Independiente oráculo numérico algebraico y contraste API futuro; falla preserva raster/text con diagnóstico apropiado.
I05 Raster: width/height/stride checked y max actual P1 4MiB, formato byte order/padding/alpha/matte premultiplied inequívocos. Transform/clip implementables en motor 7881; no segunda imagen oculta. Oráculos channel RGB/alpha0/128/255, background y stride inválido, invalidfinite/-0 si importan.
I06 Texto: encapsular UTF16 aceptado sin reinterpretación, streaming sin copia total, exactness Unverified; N/U/S/B límites y relaciones/geometry los validan host no actor. Missing mapping conserva Unicode búsqueda; inválido no publica prefijo. Rect inválido/outside/generated diagnosticado sin destacar inventado.
I07 Memoria/errores: cuotas H40/D24/source1MiB/pages256/raster4MiB/body65536 vigentes y admisión previa checked bytes reales/transitorios; inventario D1 concreto pero OPEN_COMPILE permitido. Unknown native separado. Descriptor/error payload/counters no permiten quota bypass o controlflow ambiguo. ContentFailure sólo tras input íntegro, HostError sticky; native API failures distinguibles y no evidencia falsa SourceNoText.
I08 Oráculos futuros: fixtures y expectativas anteriores outputs cubren límites exact/-1/+1, desfragmentación framing no cambia semántica, fallos digest/end/body/lateIO/cancel/Pending y geom rot/crop. Identidad física de primarias/bin obligatoria cuando se afirma hecho; main actual no prueba DLL7881. R1-R4 privados y FAILs preservados. No D0 implica P1-P5/RV204/QA Unix cerrado.
