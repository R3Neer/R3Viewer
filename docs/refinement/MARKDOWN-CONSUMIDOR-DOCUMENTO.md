## 3. Texto lógico, Unicode multirun y controles

Una **DomainSequence** consta de Text/InlineCode/FootnoteRef/CodeText/HtmlText prestados `Document::text`, SoftBreak=espacio de layout, HardBreak=salto, Resource=descriptor de layout. No Blob/String del Domain; no copiar un TextRef ni leaf completa. La etiqueta footnote es literal readonly con marca de rol, sin inventar ancla resuelta. Alt/title son secuencias distintas con DomainId propio: no duplicarlas en texto principal. La estructura define barreras: distinto Domain, bloque, HardBreak y descriptor Resource terminan el flujo inline; estilos, enlace, TextRef/Run y SoftBreak **no** fuerzan una fronteraUnicode artificial. SoftBreak inserta espacio semántico explícito; puede participar en cluster con marca combinante siguiente. HardBreak CRLF se proyecta como salto completo, no dos filas. Saltos/interblock/prefix de layout tienen origen rol/sintético, jamás TextRef de wire inventado.

La secuencia que recibe GraphemeCursor es **texto visible seguro**, después de política de controles igual a SafeTextModel: C0/DEL visibles, C1 spelling seguro, tab conserva semántica de ancho8, CRLF preservado. Lookahead cruza Runs para distinguir CRLF. NUL/ESC reales nunca se dan a Ratatui ni emitter ANSI; literal `␀` y NUL proyectado se distinguen por provenance. HtmlInert/InlineHtml son texto literal inerte, no DOM ni reinterpretaciónMarkdown.

El proveedor devuelve chunkUTF8<=4096 y offset lógico consistente, prestado cuando una pieza segura contigua sirve y, al cruzar piezas/proyección, mediante scratch fijo4096 cobrado ANTES copiar. Puede pedir lookahead/overlap de un scalar<=4B; tamaño real del slice entregado sigue<=4096. Dos buffers de chunk (forward/context/reverse reutilizados, nunca1porRun) suman8192 y se cargan al ConsumerBudget. Los bytes suministrados, context, proyectados y metadata de cada Run visitado se cargan a Work; avanzar runs vacíos no es trabajo gratis. Totales/offsets checked y UTF8boundary antes cast; ninguna tabla prefix de1entrada/byte o String del Domain.

`SegmentedIndex` retiene GraphemeCursor de secuencia completa, resuelto antes guardar/clonar checkpoint. `NextChunk` mantiene estado y offset; `PreContext(n)` recibe contexto que termina EXACTAMENTE n, retrocediendo por chunks y checkpoints del mismo Domain/identidad. No reconstruir cursor nuevo en offset arbitrario ni asumir que un char/Run es frontera grapheme. Checkpoint contiene cursorclone + LogicalPoint proveedor + line/column/visible y estados de proyección; ninguna referencia apunta a scratch efímero. Cambio de snapshot, Domain o política de proyección invalida checkpoints. RI mixedprefix/ZWJ/Hangul/Indic conservan contexto entre runs. Para consultar primero se clona checkpoint resuelto anterior; no escanear todoDomain desde0 por frame.

Preparación cancelable cuenta longitud proyectada, luego construye puntos/excepciones dispersos recorriendo secuencia; poll por bloque<=4096 y por128records, incluido largoRun/numerososvacíos. Máximo4096 checkpoints DE CAPACIDAD, stride mínimo4096 y `ceil(logicalVisibleBytes/4095)` adaptado, no 4096cadaRun. Si un intervalo necesita más trabajo que256KiB en consulta, usar Reference/unpositioned, no Work::preparation en UI para obtener una coordenada. Excepciones de cluster grande registran comienzo/final exactos/cursorafter/métricas/relación prestada, sin guardar su texto. Medir ancho mediante WidthState reverseblocks<=4096 preadmitidos, no `width(&StringGigante)` ni llamadas width porRun que cambien ancho ZWJ/RI. Preparación completa puede ser larga pero cancelable; no nuevo SLA.

Cluster que cruza Runs se emite atómicamente sólo tras admitirse tamaño<=16KiB y budget frame. Coverage es intervalo prestado de Runs+slices extremos; en frame sólo materializar metadatos necesarios ya cobrados. Un único símbolo puede contener varios estilos/links/origins. Política visual cerrada: OR de bits de estilo semántico de sus componentes (Code es bit8), vínculo como rol si hay algún vínculo; símbolo/cluster indivisible. Se conservan componentes en metadata/selección. Si hay más de un destino de enlace en el cluster, Enter presenta elección explícita, nunca seguir el primer ID silenciosamente. Diferencias de estilo dentro del mismo cluster se indican en inspector de componentes; no decir que se dibujó cada subscalar con estilo independiente. No partir a SpansRatatui en medio del cluster para fingir esa distinción. Esta política tendrá oracle específico; no cambia estilos del Document.
