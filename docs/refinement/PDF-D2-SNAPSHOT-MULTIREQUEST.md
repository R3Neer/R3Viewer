# D2 — immutable source across distinct native requests
Design only. Preserve D1 accepted inventory and current D2 source/OuterResponse checks until independent review. Original quotas10s/cleanup2s, clocks/cancel, no second kernel and all O3/O7/T/P remain unchanged.

## Demonstrated representation gap
BinarySnapshot owns one Vec/hash/origin plus capture generation/request. WriterInput::admitted and OuterResponse::new require Init generation/request equal capture IDs. Thus Metadata(request11) followed by Raster/Text(request13) cannot use the same source owner without either copying/relabeling bytes or deleting correlation. Neither is authorized. Capture IDs currently mix provenance and transaction identity.

## Proposed exact closed mechanism
Retain BinarySnapshot fields unchanged as capture provenance. NativeOwnerCore gains original_source:Arc<BinarySnapshot>, captured by the closed registry mintage factory before child/IO spawn, prepaid actual core size plus Arc headers/aliases before fields. Mintage checks input identity, full Binding, digest, generation, source SAME original Arc, original cancel/deadline and original actor state; SAMEArena alone does not mint it. The core retains that source through Pending/physical cleanup until last Drop. No raw source retag API.
Introduce private RequestSnapshot { source:Arc<BinarySnapshot>, original_scope:OriginalNativeScope, binding:Binding, metadata:Lease }. No Clone/Default/raw constructor. NativeStartLease::request_snapshot(&Arc<BinarySnapshot>) checks live first, full binding/input/generation/digest and Arc::ptr_eq(core.original_source,source), then prepays actual wrapper bytes excluding independently paid OriginalNativeScope inline, then captures SAME scope and source alias. Failed reservation/cancel/expired does not clone/reserve downstream/spawn. This scope is not a second NativeStart lease or registry permission.
RequestSnapshot getters are borrowed only. Its private try_alias checks original scope live and admits actual own wrapper/scope alias costs before clones. Original Arc storage/charge remain shared. No request-chosen Instant or cancel accepted. New request has a new closed NativeStartLease minted only after previous original capsule physically reaped (IO/child/Job/supervisor joined and escrow returned), no metadata-result shortcut.
WriterInput::admitted and OuterResponse::new migrate to the nominal RequestSnapshot parameter: Init IDs equal full request binding (including nonzero generation/request); source hash/length and native profile checks still compare original immutable source. Any IO capture retains the nominal scope/its funding. Reader output correlates same request binding AND same source Arc; request11 result never publishes for request13. Outer End/EOF remain transport only, physical publication gates unchanged.
This is a representation delta needing independent review before code. Existing raw constructor is not silently loosened; tests mechanical may retain old constructor behind cfg(test) solely for transport parsing, clearly separate from production nominal factory. All ABI/captures/layout offsets OPEN_COMPILE before outputs; estimates not acceptance.

## Prospective oracles before outputs
1. Metadata11 then Raster13/Text15 share exact source Arc/pointer/capacity/hash/origin; no source copy/re-hash/retag; aliases keep original charge until lastDrop.
2. SameArena foreign Arc with identical bytes/hash fails nominal factory BEFORE alias/reserve/spawn; same source but foreign input/revision/core fails. Old request Init/result fails new envelope even if digest matches.
3. Wrapper/scope0/N-1/exact in original Actor, cancelled/expired/exit before reserve/clone; partial failure releases only prospective wrapper charges, retains physical original owner.
4. New request is Busy/Pending until previous original physical receipts+escrowreturn; global permit/OptionNone, End, responseReady and DropJoin are not reap.
5. Original clocks and cancel unchanged through request and IO aliases; no new allowance, no new worker/thread/controller or API to substitute current live scope.
6. New fullsource/bin/runtime snapshots frozen before each output; initial correlation failures preserved; actual metadata/capture and requested allocation accounting distinguished from unknown OS/native bytes.
