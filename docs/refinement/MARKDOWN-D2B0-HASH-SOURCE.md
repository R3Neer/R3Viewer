# D2b0 R2 — continuidad HASH → SOURCE previa al código

2026-10-06. Delta mínimo sobre el intento R1, no b1/TUI. Se restaurarán autoridad tipada y visibilidad de §10.1; esta nota concreta únicamente el enlace que faltaba. Los doce controles anteriores y sus oráculos permanecen intactos como historial.

`SourcePreparationInput` permanece cerrado e inmutable: ArcOriginal, origin, inputIdentity, generation/request y optional ArcDocument/leases. Una operación HASH inicial tiene `Binding{inputIdentity,generation,request,revision,digest:None}`. La identidad se asigna una vez, nunca al completar HASH ni al pedir SOURCE.

Nuevo `PreparedSourceContext` crate-private, campos privados: `input:Arc<SourcePreparationInput>, source:Arc<DocumentSource>`. Su constructor sólo existe en la factory HASH después de `DocumentSource::new` completo, o en la factory desde Document ya validado. Verifica Arc::ptr_eq del original, origin, generation/request. No permite suministrar un digest exterior ni construir Source completo desde una etiqueta. `digest()` presta los 32 bytes de `DocumentSource::hash()`; el input conserva su identidad original. Context retiene ambos handles y los leases originales; sus capacities/headers/ref metadata se incluyen en receipt.

`SourcePrepared::Hash(Arc<PreparedSourceContext>)` sustituye PreparedHash de R1. Sólo después de join físico/final receipts/Binding hash válido, `take_validated` entrega ese Arc. Si HASH es stale/cancel/failed/Pending, no se obtiene contexto habilitado ni se inicia SOURCE.

`start_source(context:Arc<PreparedSourceContext>, revision, &mut PreparationAuthority<DI,DO>)` sustituye la entrada sin hash de R1. Captura exactamente context.input.clone() y el mismo context. Binding SOURCE incluye Some(*context.digest()), la MISMA inputIdentity/generation/request y la revision de la petición actual. Revision puede cambiar al solicitar SOURCE; original/inputIdentity/digest no cambian. Sólo estas factories cerradas construyen las bindings de Source. El kernel compara binding completo, incluyendo digest, antes de publicación.

La closure SOURCE ejecuta `SafeTextModel::from_shared(context.input.original.clone(),stop)`. `PreparedSourceModel` conserva ese mismo Arc<PreparedSourceContext>, modelo completo y receipt. No vuelve a calcular hash, no recrea SourcePreparationInput, no reabre archivo, no clona String. Si falla/cancela, conserva contexto hasta cierre/Drop; no convierte input íntegro en SourceReady.

Desde Document validado se crea el input una sola vez para esa petición y se conserva ArcDocument; context usa el Arc<DocumentSource> original existente, sin rehash. Antes de crear el input, se comprobará si Document expone ya un handle ArcSource prestado; si sólo expone &DocumentSource, se solicitará un getter crate-private de clonación Arc (sin constructor ni mutabilidad), delta explícito. No reconstruir DocumentSource desde su texto para simular identidad. La transición desde HASH no usa esta factory.

Autoridad: las factories recibirán el mismo objeto `PreparationAuthority<DI,DO>`; Source se instala en `ActiveOwner::Source`, sin owner/slot nuevo durante la continuidad. El kernel global mantiene exclusión entre objetos/sesiones y Pending; la estructura concreta de retención tipada se contrastará junto al código R2. Sólo después de reap HASH puede ocupar el slot SOURCE. b0 instancia DI=()/DO=(), sin operación Document ficticia. Las APIs y getter allocation_receipt serán crate-private, sin ampliar API externa para evitar dead_code.

Expectativas adicionales previas: HS01 HASH→SOURCE conserva ArcOriginal e inputIdentity, digest numérico previo y context Arc; HS02 Binding digest alterado o revision stale rechaza después de join; HS03 HASH cancel/Pending no habilita SOURCE y bloquea siguiente spawn; HS04 desde Document conserva ArcSource/Document lease y digest sin rehash; HS05 un error SOURCE mantiene contexto y permite nuevo start sólo tras cierre físico. No se modifican los oráculos anteriores ni se acredita pump/ConPTY.
