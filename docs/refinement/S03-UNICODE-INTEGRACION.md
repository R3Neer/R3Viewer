## Contrato API compartido (pub(crate), sin API CLI nueva)

1. **text_engine** consume `&str` inmutable o piezas prestadas identificadas; `TextIdentity {generation, domain, piece, length}` opaca producida por el propietario del modelo/pane, nunca reconstruida desde datos externos. Source identity sigue Arc/modelgeneration; borrowed identity combina estructura/generación,node,domain,pieceordinal y layoutinmutable. Small generated pieces recreadas sólo son compatibles con identidad/layout acreditado, no por coincidencia de len. Reemplazo de documento/dominio invalida índices/plan/cache.
2. `ScanContext {cancel, work: Prep|Query|Frame|Inline}` comparte contador y prueba cancel entre bloques. Query/Frame tienen quota fija candidata256KiB **de trabajo**; Prep/Inline siguen cancelables y contados sin esa quotaTUI. Cada consumidor reserva bytes antes de seg/context/proyección/width; registra examined/advanced/supplied/context/width_reserved/projection por separado. No contadorwidth=bytesprocesados. Cada operación recibe el MISMO budget del frame, no256KiB por fila/pane.
3. `GraphemeScan::next` es versión aceptadaR2: forwardhint≤4092+overlapunscalar≤4B, actualslice≤4096, contexto termina exactamente en petición y también≤4096; reserva todas relecturas. Checkpoints retienen Clone real **resuelto**, identidad/pieceoffset/len y columnas; nunca new(offsetlejano) ni set_cursor para reanudar. Nueva línea/pieza aloffset0 permite cursor inicial. Excepciones tienen rango íntegro, longitudvisible,width,posiciónline/column y cursor posterior. CursorEOF sin avance puede representarse como terminalmetadata; no se crea un cursor lejano para simularlo.
4. `WidthState` opaco conserva WidthInfo/wrapping y recibe bloques inversosUTF8≤4096 **preadmitidos**, con finishwidth. Fastpath &str usa exactamente funciónR2. Para borrowed controlprojection el adaptador añadirá fachada reversestate sobre la misma transición/tablas, no width(fragmentos) ni reglasnuevas; pruebas de equivalencia son gate de esa fachada antes de publicarla. Bloques proyectados temporales≤4096 se generan por scalar con preadmisión de rawexamined+visibleemitted, comprobando expansion/control/CRLF/lookahead por límites, sin materializarwholeleaf. Cancelar pierde todo resultado parcial. Se conservan fronteras entre piezas y semántica actual borrowedrawcluster→safeprojection; Source segmenta su visibleinmutable completo. No unificar ambas semánticas por inferencia. Sustituir también raw.chars().any(char::is_control): es una exploración completa previa que hoy no admite cancelación dentro del cluster; detección se hace por los mismos bloques preadmitidos y cancelables, nunca antes con un iterador opaco.
