Base privada: candidato UNC R2 congelado (manifest3BB930B7…). R1 y UNC R2, los oráculos independientes y sus resultados permanecen intactos. Sin cambios de wire, cuotas, Cargo, Job, controller o UI. Edición propuesta: src/document_parser.rs y tests/document_pipeline.rs; sólo helper de test de validator si hace falta un mutante directo, sin cambiar sus reglas.

Fallo confirmado por AE: `> [!note] [](x)\n> body\n` produce SpanLink de título con rango ordinal vacío. callout() crea CalloutTitleDomain sólo si title_count>0; remapea el Span a NONE y compact() indexa remap[u32MAX]. Source válida termina en panic. Wire permite dominio con cero runs y Span 0..0: no hay que borrar Link/Span ni convertir la entrada válida en error.

Corrección estrecha: durante el pase cancelable de spans existente, después de los mismos guards que conservan Quote para constructos cruzados, registrar necesidad de owner del título cuando cualquier span del dominio original vaya a la partición header (end_ordinal<=header_count). Crear título si title_count>0 O necesita_owner_header. Su ordinal_count puede ser0; remap permanece real y SpanLink/Link conservan target, origin, parent y label_count0. No fabricamos RunText vacío.

Simetría obligatoria en cuerpo: el tombstone body_count==0 sólo elimina paragraph/domain/child_item si no existe Span que vaya a la partición body. Un cuerpo `[](y)` sin runs también necesita su ParagraphDomain real, item_count0/run_count0. Retener ese bloque sin buscar primer run para recortar origin: mantener el Origin original válido del párrafo cuando no haya bodyrun, sin inventar procedencia nueva. Con body_count>0 sigue el recorte original. Empty body sin span sigue eliminándose como antes. Los links reales tienen SpanLink correspondiente; no se crea tabla auxiliar ni reescaneo global.

La partición usa el mismo criterio actual para remap y contador de necesidad, con chequeo checked_sub(marker_count/body_first) ANTES de asignaciones. Si una representación no es fiel por crossing/marker overlap sigue Quote original; no se reclasifica una construcción ambigua para satisfacer el test. Antes de compactar verificar que cualquier span vivo posee domain distinto de NONE y dentro de tabla; es guard de consistencia, no sustituto del owner obligatorio. No acceso remap fuera de rango. Cada domain adicional usa self.domain/ArenaVec ya cobrado; mismo límite64MiB, sin memoria libre ni cuota ampliada. Máximo dos booleanos locales, mismos pases O(runs+spans), poll conservado.

Variantes CRLF/UTF8 y EOF sin newline. First parser-source-only offsets/captures fijan cuáles eventos existen antes de observar R3. Independiente fixture original y oracle AE no se cambian.
